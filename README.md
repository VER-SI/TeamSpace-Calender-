# TeamSpace Calendar (Archived Internal Prototype)

> ⚠️ **Note:** This project was developed as an internal prototype during my internship at the Public Service Department (Jabatan Perkhidmatan Awam - JPA), Brunei Darussalam. To comply with non-disclosure agreements (NDAs) and governmental confidentiality standards, the original project name has been anonymized, and source code, live links, and screenshots are restricted. This repository serves as a portfolio showcase of the product design, feature specification, and technical architecture.

---

## Project Overview

**TeamSpace Calendar** is an internal-style collaboration web portal engineered to combine shared file workspace management with personal and team scheduling. Designed around the specific operational requirements gathered from department officers during my internship, it unifies document management and calendar planning into a single interface.

As an **individual project**, I designed and built the complete frontend interface alongside a partially integrated database architecture.

---

## Key Features & Functionality

### 📁 Shared File Workspace
* **Team Folders:** Workspace structures where files can be organized, viewed, and shared in a centralized interface similar to Microsoft Teams.
* **Role-Based Permissions:** Granular administrative rules where designated users hold upload, edit, or delete privileges while standard users maintain view-only access.
* **Password-Protected Access:** Individual folders feature dedicated passcode protection, requiring verification prior to unlocking directory contents.

### 📅 Integrated Personal Calendar
* **Multi-View Planner:** Google Calendar-style planning interface featuring Day, Week, and Month views.
* **Filtering & Event Management:** Dynamic filtering tools allowing users to search events, manage schedules, and organize departmental activities.
